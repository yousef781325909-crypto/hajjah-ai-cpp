# hajjah-ai-cpp
منصة تعليمية واختبارية أكاديمية تفاعلية ومتقدمة، صُممت من قبل المهندس / يوسف وليد المروني خصيصاً لطلاب التخصصات التقنية (الذكاء الاصطناعي، الأمن السيبراني، علوم الحاسوب، هندسة البرمجيات، وتقنية المعلومات). تتميز المنصة بهوية بصرية ملكية فاخرة (عاجي وذهبي) وشرح برمجي معمق يفكك كل رمز وكلمة مفتاحية في لغة C++
